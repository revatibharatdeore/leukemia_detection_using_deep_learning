# Leukemia Detection Using Deep Learning

A Deep Learning project designed to detect and classify leukemia from blood smear images, featuring an interactive web interface built with Flask.

## Flask Application Setup

### Prerequisites
* Python 3.11.0

### Setup Instructions

1. Create a Virtual Environment
   `python -m venv venv`

2. Activate the Virtual Environment
   `venv\Scripts\activate`

3. Install Dependencies
   `pip install -r requirements.txt`

4. Run the Flask Application
   `python app.py`

5. Open your Chrome browser and navigate to the local URL provided in your terminal.
